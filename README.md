- **Windows:** o instalador ainda não é assinado; no aviso do SmartScreen clique em "Mais informações" → "Executar assim mesmo".
- **Debian/Ubuntu:** `sudo apt install ./bancada-ia_0.5.1_amd64.deb`
- **AppImage:** `chmod +x Bancada-IA-0.5.1.AppImage && ./Bancada-IA-0.5.1.AppImage`

O código-fonte é privado. A pasta `s/` é a página que abre links de sessões compartilhadas.
